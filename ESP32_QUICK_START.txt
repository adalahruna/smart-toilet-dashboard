⚡ 5-MINUTE SETUP:

1. Install Arduino IDE
   → https://www.arduino.cc/en/software

2. Add ESP32 Board
   → File → Preferences → Add:
     https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   → Tools → Board → Boards Manager → Install "esp32" by Espressif

3. Install Libraries
   → Sketch → Include Library → Manage Libraries
   → Search & install: DHTesp, LiquidCrystal_I2C

4. Copy Code
   → Copy ESP32_FULL_CODE.ino content
   → Paste into new Arduino sketch
   → Edit 3 lines (WiFi, API endpoint)

5. Upload
   → Select Board: Tools → Board → ESP32 Dev Module
   → Select Port: Tools → Port → COM3 (or your port)
   → Click Upload (Ctrl+U)
   → Done! 🎉

🔴 IF UPLOAD FAILS:

Problem: "No serial port selected"
→ Connect ESP32, go Tools → Port, select COM port

Problem: "Failed to connect to ESP32"
→ Hold BOOT button, press RST, release BOOT
→ Try again immediately

Problem: "Board not found"
→ Check Tools → Board → ESP32 Dev Module is selected

Problem: Upload hangs
→ Try different USB cable or port
→ Press BOOT button during upload

See ESP32_UPLOAD_GUIDE.md for detailed troubleshooting!

📡 TESTING WITH DASHBOARD:

Local Testing (Same Network):

1. Start Next.js:
   npm run dev
   
2. Get your computer IP:
   Windows: ipconfig
   Mac: ifconfig
   (look for 192.168.1.x)

3. Update ESP32 endpoint:
   const char* API_ENDPOINT = "http://192.168.1.100:3000/api/sensor";
   (replace 100 with your IP last digit)

4. Re-upload to ESP32

5. Open http://localhost:3000 in browser

6. Watch Serial Monitor:
   [HTTP] ✓ Success! HTTP 200
   
7. Dashboard should update LIVE with sensor data!


Production Testing (Vercel):

1. Deploy Next.js:
   git push origin master
   
2. Wait for Vercel deployment

3. Update ESP32 endpoint:
   const char* API_ENDPOINT = "https://smart-toilet-dashboard.vercel.app/api/sensor";
   
4. Re-upload to ESP32

5. Verify success in Serial Monitor
