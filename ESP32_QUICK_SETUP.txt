📝 SETUP STEPS
════════════════════════════════════════════════════════════════

1. Update ESP32 Code
   - Open ESP32_UPDATED_CODE.ino
   - Change API_ENDPOINT:
     For local: const char* API_ENDPOINT = "http://192.168.x.x:3000/api/sensor";
     For production: const char* API_ENDPOINT = "https://smart-toilet-dashboard.vercel.app/api/sensor";
   - Update WiFi SSID & PASSWORD
   - Upload to ESP32

2. Test Locally
   - npm run dev (start Next.js on http://localhost:3000)
   - ESP32 will POST to http://localhost:3000/api/sensor
   - Check browser console for real-time updates
   - Check ESP32 serial monitor for POST success/errors

3. Deploy to Production
   - Deploy Next.js to Vercel: npm run build → push to main
   - Vercel automatically deploys
   - Update ESP32 API_ENDPOINT to Vercel URL
   - Re-upload ESP32 firmware

🔒 SECURITY EXPLANATION
════════════════════════════════════════════════════════════════

WHY NOT direct to Supabase?
  ❌ Supabase key would be exposed in ESP32 firmware
  ❌ Anyone can decompile firmware and extract key
  ❌ Would need to update all devices if key compromised
  ❌ No server-side validation of data
  ❌ DDoS risk (direct database access)

WHY use Next.js API?
  ✅ Supabase credentials stay on server (.env, never exposed)
  ✅ Server validates data before inserting
  ✅ Can implement rate limiting, logging, monitoring
  ✅ Single point to update business logic
  ✅ Secure & industry standard pattern

📊 DATA FLOW
════════════════════════════════════════════════════════════════

ESP32 reads sensors every 5 seconds:
  • Gas Level (MQ-135): 0-200 ppm
  • Humidity (DHT22): 0-100%
  • Temperature (DHT22): 0-50°C
  • Occupancy (PIR + Ultrasonic): 0 or 1
  • Visitor Count (cumulative today)

ESP32 creates JSON:
  {
    "room_id": "toilet_a",
    "visitor_count": 8,
    "humidity": 65.0,
    "temperature": 28.5,
    "ammonia_ppm": 120.0,
    "occupied": true
  }

ESP32 POST to Next.js API:
  POST https://your-domain.com/api/sensor
  Content-Type: application/json

Next.js validates & inserts to Supabase:
  ✓ Check all required fields present
  ✓ Check value ranges (humidity 0-100, etc)
  ✓ Insert into sensor_readings table
  ✓ Calculate cleanliness score
  ✓ Trigger WebSocket broadcast

Browser receives real-time update:
  ✓ Dashboard updates instantly (< 500ms)
  ✓ All charts & scores refresh
  ✓ Smooth animations
